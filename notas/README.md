# notas/

Apuntes por tema, resúmenes de libros y decisiones de arquitectura.

## Estructura

```
notas/
├── _plantilla-nota.md       Plantilla para apuntes de tema
├── _plantilla-libro.md      Plantilla para resumen de libro
├── _plantilla-adr.md        Plantilla para Architecture Decision Record
├── libros/                  Un fichero por libro
└── adr/                     Un fichero por decisión de arquitectura
```

## Regla

Cada bloque técnico termina con algo escrito aquí. Una nota de 5 líneas es válida; cero notas no lo es.
