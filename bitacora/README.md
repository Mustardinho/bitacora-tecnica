# bitacora/

Registro semanal. Un fichero por semana ISO: `AAAA-Wnn.md` (ej. `2026-W35.md`).

Se rellena el domingo, en la revisión de 20 minutos. Sirve para dos cosas:
1. Ver si el ritmo de 9-10 h/semana se sostiene de verdad.
2. Detectar patrones de fallo (si siempre falla el mismo día, hay que cambiar la franja, no la voluntad).
